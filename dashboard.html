Inside a packet, each document carries its own stamp: MET_FROM_DOCUMENT, MISSING, MISMATCH, EXPIRED, NOT_APPLICABLE, UNVERIFIED, or REVIEW_REQUIRED. INDEPENDENTLY_VERIFIED is used only after a separate permitted confirmation — a certificate alone never counts as verified coverage, and there is no single "approved" badge.
